# SmartColorDetection
A Python project that detects red, green, and blue objects in real time using OpenCV and a webcam.

## Project Overview

This project uses Python and OpenCV to detect colored objects in real time through a webcam.

The system recognizes the following colors:
- Red
- Green
- Blue

When a colored object is detected, the program draws a rectangle around it and displays its color name.

---

## Technologies Used

- Python
- OpenCV
- NumPy

---

## Requirements

Install the required libraries:
pip install opencv-python numpy

---

## How to Run

Run the following command:
python smart_color_detection.py

---

## Project Output

The webcam opens and detects:
- Red objects
- Green objects
- Blue objects

A colored rectangle and the color name are displayed on the screen.
